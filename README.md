# Employee Directory – HEPL Technologies

A responsive Employee Directory web application designed to display employee information in a clean, organized, and user-friendly interface. This project helps users view employee details through a structured directory layout.

## 🚀 Features

- **Employee Listing:** Display employee details in an organized card layout.
- **Employee Profiles:** Show employee names, designations, and profile initials.
- **Responsive Design:** Adapt the layout for desktop, tablet, and mobile devices.
- **Reusable Components:** Build a modular and maintainable user interface using React components.
- **Clean UI:** Provide a simple and professional interface for employee information.
- **Maintainable Code:** Separate components and CSS files for better project organization.

## 🛠️ Technologies Used

- **React.js** – Building reusable UI components.
- **JavaScript (ES6+)** – Implementing application logic.
- **HTML5** – Structuring the application.
- **CSS3** – Styling and responsive layouts.
- **Font Awesome** – Displaying icons.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Visual Studio Code (recommended)

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

### Step 2: Navigate to the Project Folder

```bash
cd Employees-Directory
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
